# リンクも広告も、全部消します

**ページ内のリンクと広告を一括削除。誤クリックもページ移動もさせません。読みたい内容だけを残します。**

ページを開いて拡張機能のボタンを押すと、ページ内のリンク（`<a>`）をまとめて削除します。
リンクとして配置されている広告も一緒に消えるので、余計なページ移動を防いで本文に集中できます。

ページを更新すると元に戻ります。

## 使い方

1. Chromeにこの拡張機能を読み込む
2. リンクや広告を消したいページを開く
3. 拡張機能の「余計なリンク消します」ボタンを押す
4. ページ内のリンクが消える
5. 元に戻したいときはページを更新

## 実装

処理はこれだけです。

```js
document.querySelectorAll("a").forEach(el => el.remove());
```

本文抽出やサイト別判定などは行いません。
